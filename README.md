# Ultimate Player 🏀
Appli Android : archétype de basketteur selon taille, poids, envergure et style de jeu.

## Obtenir l'APK
1. Envoie tout le contenu de ce dossier dans un dépôt GitHub (ex. `Ultimate-Player`).
2. Onglet **Actions** → workflow **Build APK** (se lance tout seul à chaque envoi).
3. Quand c'est vert ✅ → ouvre le build → **Artifacts** → `UltimatePlayer-apk` → télécharge, dézippe, installe `app-debug.apk`.
